Tabs & spaces

New tabs with no opener start in the space you used last. This space is used when there isn't one yet.

Icons keep every space in view, as in Arc; a space without an icon shows a dot, and its name appears on hover.

When off, the top favorites bar is shared across spaces in this Chrome profile. Turn on to show only the current space’s favorites. Switching this setting keeps your favorites and their space assignments.

Each window’s sidebar lists the current space’s open tabs and the top-bar favorites of all your windows as one list, one entry per page. Choosing a page that is open only in another window opens it in the window you are in, and that window keeps its own tab. Turn off to show only each window’s own tabs.

Turn off to show new tabs at the bottom. Favorites always follow bookmark order.

A new tab closes by itself when you switch to another tab without typing an address or opening a site. It never closes a window’s last tab, a pinned tab, a favorite, or a tab that has already been to a site.

When off, only the active tab appears under a collapsed folder.

Mirror space membership, names, colors, and tab order to Chrome groups. Spaces stay saved independently. Turning this off leaves existing groups unchanged.

Pinned tab matching

Comma-separated hosts (optionally host:port) whose URLs are distinguished by their query string, so each URL pins as its own entry. For example: localhost:6969

Auto-archiving

Archive inactive tabs automatically. Pinned tabs and tabs playing audio stay open.

Minutes of inactivity before a tab is archived.

Colors

Customize the palette used throughout the extension. Each color has a light and a dark value, and the sidebar uses the one that matches your system theme. A dark value you have not changed keeps the built-in dark color.
